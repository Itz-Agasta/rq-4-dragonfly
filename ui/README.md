# ui

Operator console. Vite + React + TypeScript, built to a static bundle that
`dragonfly-core` serves on :8787 and Chromium runs fullscreen in kiosk mode.

Six screens: OPS, TWIN, ANALYSIS, SIMULATE, REPLAY, FLEET. None are built yet. The
visual contract is `design.md`; the theme tokens are `src/index.css`.
